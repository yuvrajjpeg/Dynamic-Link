Dynamic Bridge is installed

  1. Restart DaVinci Resolve and After Effects.
  2. In Resolve, open Preferences → System → General and set External scripting to Local.
  3. In After Effects scripting preferences, turn on Allow Scripts to Write Files and Access Network.
  4. Select a shot and choose Workspace → Scripts → Utility → Replace with After Effects Composition.

Install details are saved to ~/Library/Logs/Dynamic Bridge Install.log.
