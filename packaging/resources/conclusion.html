Dynamic Bridge setup

Install After Effects separately if it is missing, then rerun this installer. Restart both applications after installation.

Automatic updates — Resolve Studio 21.1+:

  1. Enable External scripting → Local in Resolve and Allow Scripts to Write Files and Access Network in After Effects.
  2. Select a video clip in Resolve. Choose Workspace → Scripts → Utility → Replace with After Effects Composition.
  3. Animate the generated composition in After Effects and press Cmd+S.
  4. Keep Resolve and the original timeline open. The finished background render becomes a new take automatically.

Updates require rendering time. Run Resume AE Updates after restarting your computer.

Manual workflow — Free, Studio or App Store: Send to After Effects → Render for Resolve in the AE panel → Apply AE Render in Resolve.

Setup details: ~/Library/Logs/Dynamic Bridge Install.log.
