Dynamic Bridge is installed

  1. Restart DaVinci Resolve and After Effects.
  2. In After Effects scripting preferences, turn on Allow Scripts to Write Files and Access Network.
  3. In Resolve, select a clip and choose Workspace → Scripts → Dynamic Bridge - Send to After Effects.
  4. In After Effects, open File → Scripts → Resolve AE Bridge, animate, then click Render for Resolve.
  5. Back in Resolve, choose Dynamic Bridge - Apply AE Render. The render becomes a new take on the clip.

Works with DaVinci Resolve Free, Studio and the Mac App Store edition. Install details are saved to ~/Library/Logs/Dynamic Bridge Install.log.
