Dynamic Bridge

Animate a Resolve shot in After Effects and return the finished render as a new take.

Automatic save updates: macOS, Resolve Studio 21.1+, Python 3.9+ and After Effects with aerender. Save the linked AE project; the background worker renders and updates Resolve.

Manual workflow: Resolve Free, Studio and Mac App Store editions can send a shot, render it in AE, and apply the result with the bridge menu commands.

This installer adds Resolve menu scripts, bridge files in your user Library, and the After Effects companion when AE is installed. It does not install either host application.

Automatic updates take time to render. Native AE/Resolve round-trip verification is still pending.
