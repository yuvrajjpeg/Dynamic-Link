    Bridge installation complete

    Restart Resolve, then choose Workspace → Scripts → Utility → Replace with After Effects Composition.

    Finish setup

    1. Restart DaVinci Resolve and After Effects.
    2. In Resolve, open Preferences → System → General and set External scripting to Local.
    3. In After Effects scripting preferences, turn on Allow Scripts to Write Files and Access Network.
    4. Select a Resolve shot and run the replacement script. Animate in AE and press Cmd+S. A compatible QuickTime template is configured automatically when available; AE will explain if a custom preset is needed.
